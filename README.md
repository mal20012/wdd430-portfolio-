# wdd430-portfolio

A portfolio site built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
